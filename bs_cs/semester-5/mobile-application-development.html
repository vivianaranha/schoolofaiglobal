Code Examples

Step-by-step walkthroughs connect ideas to executable artifacts.

Rendering a Simple Mobile Screen

JAVASCRIPT example with explanation and expected behavior.

import { View, Text, Button } from 'react-native';

export default function CounterScreen() {
  let taps = 0;

  return (
    <View style={{ padding: 24 }}>
      <Text accessibilityRole="header">Tap Tracker</Text>
      <Button title="Tap me" onPress={() => console.log(++taps)} />
    </View>
  );
}

Why This Works

  • Compose a screen from accessible UI primitives rather than raw platform widgets.
  • Use layout styles to create spacing that works well on small screens.
  • Attach behavior through an event handler so user input triggers application logic.
  • Treat console logging as a first debugging step before introducing persistent state.

Expected Output

The app renders a header and a button that logs interaction events.

Calling a REST Endpoint from the Browser

JAVASCRIPT example with explanation and expected behavior.

async function loadCourses() {
  const response = await fetch('/api/courses');
  const courses = await response.json();

  const list = document.querySelector('#course-list');
  list.innerHTML = courses
    .map(course => '<li>' + course.title + '</li>')
    .join('');
}

loadCourses();

Why This Works

  • Use the Fetch API to request data from the server without reloading the page.
  • Parse the JSON payload into ordinary JavaScript objects.
  • Transform each record into HTML for presentation to the user.
  • Keep network concerns and rendering concerns in one small, understandable workflow.

Expected Output

The page fetches JSON data and renders a list of course titles.
