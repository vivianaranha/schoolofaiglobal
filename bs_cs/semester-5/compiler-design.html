Start by understanding the plain-language purpose of the idea, the vocabulary attached to it, and the kinds of questions it helps us answer. In beginner-friendly terms, this module asks: what problem does this concept solve, and why would a computing professional care about it?

At a deeper level, we connect the purpose and structure of a compiler to the broader systems and infrastructure pathway. We examine the assumptions behind the concept, how it interacts with adjacent topics in Semester 5: Artificial Intelligence and Advanced Systems, and what changes when systems become larger, faster, more distributed, or more safety-critical. Code Examples

Step-by-step walkthroughs connect ideas to executable artifacts.

Scanning Characters into Simple Tokens

C example with explanation and expected behavior.

#include <ctype.h>
#include <stdio.h>

int main() {
    char source[] = "sum = total + 42";
    for (int i = 0; source[i] != '\0'; i++) {
        if (isalpha(source[i])) printf("LETTER:%c\n", source[i]);
        else if (isdigit(source[i])) printf("DIGIT:%c\n", source[i]);
        else if (!isspace(source[i])) printf("SYMBOL:%c\n", source[i]);
    }
}

Why This Works

  • Read source text one character at a time so the scanner can classify input incrementally.
  • Use character-category helpers to separate letters, digits, and symbols.
  • Ignore whitespace because it often has no meaning at the lexical level.
  • Recognize that real lexers combine characters into larger tokens such as identifiers and numbers.

Expected Output

LETTER:s ... SYMBOL:= ... DIGIT:4 ...

A High-Level Recursive-Descent Parsing Strategy

TEXT example with explanation and expected behavior.

parseExpression()
    left <- parseTerm()
    WHILE next token is '+' or '-'
        operator <- consume token
        right <- parseTerm()
        left <- new BinaryNode(operator, left, right)
    RETURN left

Why This Works

  • Map grammar rules to functions so the parser mirrors the language structure.
  • Parse higher-precedence units first and combine them as operators appear.
  • Create syntax-tree nodes during parsing instead of performing evaluation immediately.
  • Use grammar design to control how expressions are grouped.

Expected Output

The parser builds a syntax tree that preserves precedence and associativity.
