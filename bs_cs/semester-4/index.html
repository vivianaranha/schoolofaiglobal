Semester Theme

This overview page helps learners understand how the subjects fit together.

Turn solid foundations into user-facing systems, secure services, and structured project delivery.

Learning Goals

  • Write more scalable programs using advanced language features and clean design patterns.
  • Build, secure, and troubleshoot web and networked applications.
  • Understand theoretical models of computation alongside user-centered design principles.
  • Plan and manage software work using realistic delivery practices.
