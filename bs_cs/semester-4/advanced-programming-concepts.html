Code Examples

Step-by-step walkthroughs connect ideas to executable artifacts.

Using Inheritance and Polymorphism

JAVA example with explanation and expected behavior.

abstract class Report {
    abstract void generate();
}

class SummaryReport extends Report {
    @Override
    void generate() {
        System.out.println("Generating summary report");
    }
}

class AuditReport extends Report {
    @Override
    void generate() {
        System.out.println("Generating audit report");
    }
}

public class Main {
    public static void main(String[] args) {
        Report[] reports = { new SummaryReport(), new AuditReport() };
        for (Report report : reports) {
            report.generate();
        }
    }
}

Why This Works

  • Use an abstract base type to define behavior that every report must support.
  • Override the shared method differently in each subclass.
  • Store different object types in the same array through the parent reference.
  • Call the same method name and let dynamic dispatch choose the correct implementation.

Expected Output

Generating summary report\nGenerating audit report

Breaking a Problem into Reusable Functions

PYTHON example with explanation and expected behavior.

def average(scores):
    return sum(scores) / len(scores)


def grade(score):
    if score >= 90:
        return "A"
    if score >= 80:
        return "B"
    if score >= 70:
        return "C"
    return "Needs Improvement"

student_scores = [88, 92, 79, 95]
class_average = average(student_scores)
print("Class average:", round(class_average, 2))
print("Overall grade:", grade(class_average))

Why This Works

  • Separate calculation logic from grading logic so each part has one clear responsibility.
  • Reuse built-in aggregation functions to keep the code short and readable.
  • Return values from functions so other parts of the program can build on them.
  • Round the result at the presentation layer rather than inside the calculation function.

Expected Output

Class average: 88.5\nOverall grade: B
