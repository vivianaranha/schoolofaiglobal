Learning Outcomes

By the end of this subject, a self-paced learner should be able to do the following with confidence.

  • Explain alphabets, strings, and formal languages within realistic theory of computation scenarios.
  • Apply deterministic finite automata within realistic theory of computation scenarios.
  • Analyze nondeterminism and equivalent models within realistic theory of computation scenarios.
  • Design regular expressions and pattern languages within realistic theory of computation scenarios.
  • Evaluate context-free grammars and parse structure within realistic theory of computation scenarios.
  • Interpret pushdown automata and stack-based recognition within realistic theory of computation scenarios.
  • Implement turing machines and universal computation within realistic theory of computation scenarios.
  • Compare decidability and undecidable problems within realistic theory of computation scenarios.
  • Troubleshoot complexity classes and tractability within realistic theory of computation scenarios.
  • Connect applications in compilers and language design within realistic theory of computation scenarios.

A High-Level Recursive-Descent Parsing Strategy

TEXT example with explanation and expected behavior.

parseExpression()
    left <- parseTerm()
    WHILE next token is '+' or '-'
        operator <- consume token
        right <- parseTerm()
        left <- new BinaryNode(operator, left, right)
    RETURN left

Why This Works

  • Map grammar rules to functions so the parser mirrors the language structure.
  • Parse higher-precedence units first and combine them as operators appear.
  • Create syntax-tree nodes during parsing instead of performing evaluation immediately.
  • Use grammar design to control how expressions are grouped.

Expected Output

The parser builds a syntax tree that preserves precedence and associativity.
