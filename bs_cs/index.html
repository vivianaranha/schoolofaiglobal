Program Overview

This library is designed as a browser-based curriculum portal that can be opened locally without a server.

The program starts with computational thinking and mathematical literacy, grows into programming and system design, then expands into databases, networking, web development, AI, cloud platforms, cybersecurity, research, product thinking, and career readiness.

Each subject page includes learning outcomes, ten modules, deep-dive lessons, activities, assignments, a twenty-question quiz, a final project or assessment, and recommended references for further study.

03

Learning Pathway

The sequence below shows how the degree grows from fundamentals to specialization and professional delivery.

Semester 1

Foundations of Computing

Build computational thinking, mathematical confidence, and a first-principles understanding of computers.

  • Understand what computer science covers, from hardware to software and society.
  • Write first programs, reason about logic, and model simple computational solutions.
  • Develop mathematical fluency for binary systems, algebra, and structured problem solving.

Semester 2

Core Programming and Systems

Move from basics to modular software, structured data, formal reasoning, and core system design.

  • Design object-oriented programs with reusable abstractions and clear interfaces.
  • Choose and implement efficient data structures for common software tasks.
  • Strengthen discrete, algebraic, and architectural reasoning used throughout the degree.

Semester 3

Algorithms, Databases, and Systems

Learn how efficiency, data modeling, operating systems, and networks shape real software.

  • Analyze algorithm performance and explain why one solution scales better than another.
  • Model, query, and manage reliable relational databases.
  • Understand operating-system services, networking fundamentals, and disciplined software engineering.

Semester 4

Software Development and Networking

Turn solid foundations into user-facing systems, secure services, and structured project delivery.

  • Write more scalable programs using advanced language features and clean design patterns.
  • Build, secure, and troubleshoot web and networked applications.
  • Understand theoretical models of computation alongside user-centered design principles.

Semester 5

Artificial Intelligence and Advanced Systems

Expand into intelligent systems, distributed computing, cloud platforms, and data-intensive design.

  • Explain foundational AI methods and train introductory machine-learning models.
  • Understand how compilers, distributed systems, and cloud platforms support scalable software.
  • Design mobile and analytics-oriented applications that use structured data effectively.

Semester 6

Data, Security, and Scalable Applications

Work with modern data platforms, security operations, scalable delivery pipelines, and industry-style execution.

  • Tune, secure, and scale data systems beyond the introductory database model.
  • Use modern tools for security defense, big-data processing, DevOps, and IoT integration.
  • Explore electives that broaden technical range across blockchain, graphics, NLP, and design.

Semester 7

Specialization and Industry Readiness

Specialize in advanced AI, cloud-native systems, security, and emerging computing frontiers.

  • Train and evaluate more advanced AI and deep-learning systems.
  • Design cloud-native applications, security governance plans, and research-driven investigations.
  • Choose specializations that align with industry roles, graduate study, or entrepreneurship.

Semester 8

Capstone, Leadership, and Emerging Technologies

Synthesize advanced technical work with leadership, ethics, deployment, and career readiness.

  • Design and evaluate real-world generative AI and responsible-computing solutions.
  • Understand product strategy, entrepreneurship, deployment, and enterprise architecture trade-offs.
  • Complete internship, capstone, and portfolio work that demonstrates professional readiness.
