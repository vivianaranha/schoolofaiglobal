Modeling a Student as a Class

JAVA example with explanation and expected behavior.

class Student {
    private String name;
    private int credits;

    Student(String name, int credits) {
        this.name = name;
        this.credits = credits;
    }

    void addCredits(int value) {
        credits += value;
    }

    void display() {
        System.out.println(name + " has " + credits + " credits.");
    }
}

public class Main {
    public static void main(String[] args) {
        Student learner = new Student("Ava", 12);
        learner.addCredits(3);
        learner.display();
    }
}

Why This Works

  • Encapsulate the student state inside private fields so outside code uses methods instead of direct edits.
  • Initialize new objects through a constructor that guarantees valid starting values.
  • Update object state through a behavior-oriented method rather than scattered arithmetic.
  • Create an instance in main to show how the class becomes a reusable blueprint.

Expected Output

Ava has 15 credits.

Using Inheritance and Polymorphism

JAVA example with explanation and expected behavior.

abstract class Report {
    abstract void generate();
}

class SummaryReport extends Report {
    @Override
    void generate() {
        System.out.println("Generating summary report");
    }
}

class AuditReport extends Report {
    @Override
    void generate() {
        System.out.println("Generating audit report");
    }
}

public class Main {
    public static void main(String[] args) {
        Report[] reports = { new SummaryReport(), new AuditReport() };
        for (Report report : reports) {
            report.generate();
        }
    }
}

Why This Works

  • Use an abstract base type to define behavior that every report must support.
  • Override the shared method differently in each subclass.
  • Store different object types in the same array through the parent reference.
  • Call the same method name and let dynamic dispatch choose the correct implementation.

Expected Output

Generating summary report\nGenerating audit report
