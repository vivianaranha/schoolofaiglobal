  • Analyze instruction execution stages and datapaths within realistic computer architecture scenarios.
  • Design risc, cisc, and architectural trade-offs within realistic computer architecture scenarios.
  • Evaluate pipelining and throughput improvement within realistic computer architecture scenarios.
  • Interpret cache organization and locality within realistic computer architecture scenarios.
  • Implement virtual memory and address translation basics within realistic computer architecture scenarios.
  • Compare input/output organization and interrupt ideas within realistic computer architecture scenarios.
