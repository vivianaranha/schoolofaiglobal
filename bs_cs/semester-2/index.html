Semester Theme

This overview page helps learners understand how the subjects fit together.

Move from basics to modular software, structured data, formal reasoning, and core system design.

Learning Goals

  • Design object-oriented programs with reusable abstractions and clear interfaces.
  • Choose and implement efficient data structures for common software tasks.
  • Strengthen discrete, algebraic, and architectural reasoning used throughout the degree.
  • Connect web foundations and professional ethics to practical software work.
