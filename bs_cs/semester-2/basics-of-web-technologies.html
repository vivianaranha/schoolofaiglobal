A Simple Accessible Form Structure

HTML example with explanation and expected behavior.

<form id="signup-form">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>

  <label for="role">Role</label>
  <select id="role" name="role">
    <option>Student</option>
    <option>Mentor</option>
  </select>

  <button type="submit">Create Account</button>
</form>

Why This Works

  • Pair every form control with a label so users and assistive technologies understand intent.
  • Use semantic input types to get better browser validation and mobile keyboards.
  • Keep the structure simple enough to style and validate progressively.
  • Start with accessibility and semantics before adding JavaScript behavior.

Expected Output

The browser presents labeled, keyboard-friendly controls with built-in validation support.

Calling a REST Endpoint from the Browser

JAVASCRIPT example with explanation and expected behavior.

async function loadCourses() {
  const response = await fetch('/api/courses');
  const courses = await response.json();

  const list = document.querySelector('#course-list');
  list.innerHTML = courses
    .map(course => '<li>' + course.title + '</li>')
    .join('');
}

loadCourses();

Why This Works

  • Use the Fetch API to request data from the server without reloading the page.
  • Parse the JSON payload into ordinary JavaScript objects.
  • Transform each record into HTML for presentation to the user.
  • Keep network concerns and rendering concerns in one small, understandable workflow.

Expected Output

The page fetches JSON data and renders a list of course titles.
