Building a Simple Linked List Node Chain

CPP example with explanation and expected behavior.

#include <iostream>
using namespace std;

struct Node {
    int value;
    Node* next;
};

int main() {
    Node first{10, nullptr};
    Node second{20, nullptr};
    Node third{30, nullptr};

    first.next = &second;
    second.next = &third;

    for (Node* current = &first; current != nullptr; current = current->next) {
        cout << current->value << " ";
    }
}

Why This Works

  • Create a node structure that stores both data and a pointer to the next node.
  • Link objects together dynamically rather than relying on contiguous array positions.
  • Traverse by following pointers until the null terminator is reached.
  • Observe how insertion flexibility comes at the cost of pointer management.

Recursive Divide-and-Conquer Sorting

PYTHON example with explanation and expected behavior.

def merge_sort(values):
    if len(values) <= 1:
        return values

    middle = len(values) // 2
    left = merge_sort(values[:middle])
    right = merge_sort(values[middle:])

    merged = []
    while left and right:
        if left[0] <= right[0]:
            merged.append(left.pop(0))
        else:
            merged.append(right.pop(0))

    return merged + left + right

print(merge_sort([9, 2, 7, 1, 5]))

Why This Works

  • Use the base case to stop recursion when a subproblem is already sorted.
  • Split the list into smaller halves until each piece is easy to handle.
  • Merge the sorted halves by repeatedly taking the smallest front element.
  • Recognize that divide-and-conquer trades extra space for predictable performance.

[1, 2, 5, 7, 9]
