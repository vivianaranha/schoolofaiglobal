Tracing Binary Search with Pseudocode

TEXT example with explanation and expected behavior.

BINARY-SEARCH(list, target)
    low <- 0
    high <- length(list) - 1

    WHILE low <= high
        mid <- floor((low + high) / 2)
        IF list[mid] = target
            RETURN mid
        ELSE IF list[mid] < target
            low <- mid + 1
        ELSE
            high <- mid - 1
    RETURN not found

Why This Works

  • Keep a search window defined by low and high indices.
  • Inspect the middle position instead of scanning every element.
  • Discard the half that cannot contain the target after each comparison.
  • Stop when the target is found or when the search window becomes empty.

Expected Output

For list [3, 7, 9, 14, 20] and target 14, the algorithm returns index 3.

Recursive Divide-and-Conquer Sorting

PYTHON example with explanation and expected behavior.

def merge_sort(values):
    if len(values) <= 1:
        return values

    middle = len(values) // 2
    left = merge_sort(values[:middle])
    right = merge_sort(values[middle:])

    merged = []
    while left and right:
        if left[0] <= right[0]:
            merged.append(left.pop(0))
        else:
            merged.append(right.pop(0))

    return merged + left + right

print(merge_sort([9, 2, 7, 1, 5]))

Why This Works

  • Use the base case to stop recursion when a subproblem is already sorted.
  • Split the list into smaller halves until each piece is easy to handle.
  • Merge the sorted halves by repeatedly taking the smallest front element.
  • Recognize that divide-and-conquer trades extra space for predictable performance.

Expected Output

[1, 2, 5, 7, 9]
