Learning Outcomes

By the end of this subject, a self-paced learner should be able to do the following with confidence.

  • Explain network types, media, and topologies within realistic computer networks i scenarios.
  • Apply osi and tcp/ip layered models within realistic computer networks i scenarios.
  • Analyze ip addressing and subnetting fundamentals within realistic computer networks i scenarios.
  • Design routing, switching, and forwarding logic within realistic computer networks i scenarios.
  • Evaluate ethernet and local network behavior within realistic computer networks i scenarios.
  • Interpret tcp, udp, and transport trade-offs within realistic computer networks i scenarios.
  • Implement dns, http, ftp, smtp, and application protocols within realistic computer networks i scenarios.
  • Compare common network devices and their responsibilities within realistic computer networks i scenarios.
  • Troubleshoot performance, latency, and throughput thinking within realistic computer networks i scenarios.
  • Connect security basics and operational troubleshooting within realistic computer networks i scenarios.

Code Examples

Step-by-step walkthroughs connect ideas to executable artifacts.

Checking Reachability and Name Resolution

BASH example with explanation and expected behavior.

ping -c 4 example.com
nslookup example.com
traceroute example.com

Why This Works

  • Ping verifies basic reachability and round-trip time.
  • Name resolution tools confirm whether the domain maps to the expected address.
  • Traceroute reveals where traffic moves hop by hop.
  • Together these commands form a first-pass troubleshooting routine.

Expected Output

Returns latency, DNS information, and path details for the destination host.
Try It Yourself: Change one variable, constraint, or input assumption and predict how the output should change before you run it.
