Semester Theme

This overview page helps learners understand how the subjects fit together.

Learn how efficiency, data modeling, operating systems, and networks shape real software.

Learning Goals

  • Analyze algorithm performance and explain why one solution scales better than another.
  • Model, query, and manage reliable relational databases.
  • Understand operating-system services, networking fundamentals, and disciplined software engineering.
  • Document technical decisions clearly for developers, users, and stakeholders.
