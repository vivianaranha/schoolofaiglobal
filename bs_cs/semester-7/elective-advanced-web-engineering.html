Calling a REST Endpoint from the Browser

JAVASCRIPT example with explanation and expected behavior.

async function loadCourses() {
  const response = await fetch('/api/courses');
  const courses = await response.json();

  const list = document.querySelector('#course-list');
  list.innerHTML = courses
    .map(course => '<li>' + course.title + '</li>')
    .join('');
}

loadCourses();

Why This Works

  • Use the Fetch API to request data from the server without reloading the page.
  • Parse the JSON payload into ordinary JavaScript objects.
  • Transform each record into HTML for presentation to the user.
  • Keep network concerns and rendering concerns in one small, understandable workflow.

Expected Output

The page fetches JSON data and renders a list of course titles.

A Minimal Continuous Integration Workflow

YAML example with explanation and expected behavior.

name: test-and-build
on: [push, pull_request]
jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm test

Why This Works

  • Attach the workflow to source control events so validation happens automatically.
  • Recreate the runtime environment consistently in a hosted runner.
  • Install dependencies cleanly to reduce “works on my machine” drift.
  • Fail early when tests do not pass before deployment is attempted.

Expected Output

Every push or pull request triggers an automated checkout, install, and test run.

Containerizing a Small Web Service

DOCKERFILE example with explanation and expected behavior.

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]

Why This Works

  • Choose a lightweight base image that already includes the runtime you need.
  • Set a working directory so later instructions remain consistent.
  • Copy dependency manifests first to improve rebuild performance through caching.
  • Expose the service port and define the startup command for deployment.

Expected Output

Builds an image that installs dependencies and starts the app on port 3000.
