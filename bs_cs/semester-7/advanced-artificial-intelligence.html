State-Space Search with a Queue

PYTHON example with explanation and expected behavior.

from collections import deque


def breadth_first_search(graph, start, goal):
    queue = deque([(start, [start])])
    visited = {start}

    while queue:
        node, path = queue.popleft()
        if node == goal:
            return path
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))

campus = {
    'Entrance': ['Library', 'Lab'],
    'Library': ['Entrance', 'Cafeteria'],
    'Lab': ['Entrance', 'Server Room'],
    'Cafeteria': ['Library'],
    'Server Room': ['Lab']
}

print(breadth_first_search(campus, 'Entrance', 'Server Room'))

Why This Works

  • Represent the environment as a graph of states and possible moves.
  • Track both the current node and the path taken so the algorithm can explain its result.
  • Use a queue to explore the graph level by level.
  • Maintain a visited set to prevent infinite loops in cyclic graphs.

Expected Output

['Entrance', 'Lab', 'Server Room']

A Tiny End-to-End Classification Workflow

PYTHON example with explanation and expected behavior.

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

features, labels = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(features, labels, test_size=0.2, random_state=42)

model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)
predictions = model.predict(X_test)

print('Accuracy:', round(accuracy_score(y_test, predictions), 3))

Why This Works

  • Load a prepared dataset so the workflow can focus on modeling decisions.
  • Separate training and testing data to avoid evaluating on memorized examples.
  • Fit a simple interpretable model before moving to more complex ones.
  • Measure performance with a clear metric that can be compared across experiments.

Expected Output

Accuracy: 1.0
