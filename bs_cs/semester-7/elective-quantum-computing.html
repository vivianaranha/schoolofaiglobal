Code Examples

Creating a Tiny Quantum Circuit

PYTHON example with explanation and expected behavior.

from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure([0, 1], [0, 1])
print(qc)

Why This Works

  • Initialize a circuit with qubits and classical bits for measurement results.
  • Apply a Hadamard gate to place one qubit into superposition.
  • Use a controlled-NOT gate to create entanglement between the qubits.
  • Measure to convert quantum state into classical output that can be observed.

Expected Output

Prints a circuit that creates superposition and entanglement before measurement.
