Code Examples

Step-by-step walkthroughs connect ideas to executable artifacts.

Training a Tiny Neural Network

PYTHON example with explanation and expected behavior.

import torch
from torch import nn

model = nn.Sequential(
    nn.Linear(4, 8),
    nn.ReLU(),
    nn.Linear(8, 3)
)

inputs = torch.rand(16, 4)
targets = torch.randint(0, 3, (16,))
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

for _ in range(20):
    predictions = model(inputs)
    loss = loss_fn(predictions, targets)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print(round(loss.item(), 4))

Why This Works

  • Define layers that map input features to hidden representations and output classes.
  • Choose a loss function that matches the prediction task.
  • Run forward and backward passes inside the training loop.
  • Update parameters with an optimizer that improves the model gradually over time.

Expected Output

Prints a loss value that generally decreases over training iterations.
