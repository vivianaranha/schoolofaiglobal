Semester Theme

This overview page helps learners understand how the subjects fit together.

Work with modern data platforms, security operations, scalable delivery pipelines, and industry-style execution.

Learning Goals

  • Tune, secure, and scale data systems beyond the introductory database model.
  • Use modern tools for security defense, big-data processing, DevOps, and IoT integration.
  • Explore electives that broaden technical range across blockchain, graphics, NLP, and design.
  • Deliver production-style work through labs and an industry-oriented project.
