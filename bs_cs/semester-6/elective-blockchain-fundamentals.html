Code Examples

Step-by-step walkthroughs connect ideas to executable artifacts.

Recording Values in a Smart Contract

SOLIDITY example with explanation and expected behavior.

pragma solidity ^0.8.20;

contract CourseLedger {
    mapping(address => uint256) public credits;

    function addCredit(address learner, uint256 amount) public {
        credits[learner] += amount;
    }
}

Why This Works

  • Use a mapping when data should be looked up by key efficiently.
  • Declare state variables inside the contract so the blockchain persists them.
  • Expose a function that changes state through a transaction.
  • Notice that every state change becomes part of a transparent shared ledger.

Expected Output

The contract stores and exposes an on-chain credit total for each address.
