Drawing with the HTML Canvas API

JAVASCRIPT example with explanation and expected behavior.

const canvas = document.querySelector('canvas');
const ctx = canvas.getContext('2d');

ctx.fillStyle = '#1d4ed8';
ctx.fillRect(20, 20, 120, 80);
ctx.strokeStyle = '#0f172a';
ctx.strokeRect(20, 20, 120, 80);

Why This Works

  • Get the rendering context from the canvas element before issuing drawing commands.
  • Set style properties so later draw calls use the intended colors.
  • Fill the shape first to create visible area, then stroke it to emphasize edges.
  • Recognize the immediate-mode nature of canvas rendering compared with retained DOM layout.
