A Tiny End-to-End Classification Workflow

PYTHON example with explanation and expected behavior.

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

features, labels = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(features, labels, test_size=0.2, random_state=42)

model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)
predictions = model.predict(X_test)

print('Accuracy:', round(accuracy_score(y_test, predictions), 3))

Why This Works

  • Load a prepared dataset so the workflow can focus on modeling decisions.
  • Separate training and testing data to avoid evaluating on memorized examples.
  • Fit a simple interpretable model before moving to more complex ones.
  • Measure performance with a clear metric that can be compared across experiments.

Expected Output

Accuracy: 1.0

A Minimal Continuous Integration Workflow

YAML example with explanation and expected behavior.

name: test-and-build
on: [push, pull_request]
jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm test

Why This Works

  • Attach the workflow to source control events so validation happens automatically.
  • Recreate the runtime environment consistently in a hosted runner.
  • Install dependencies cleanly to reduce “works on my machine” drift.
  • Fail early when tests do not pass before deployment is attempted.

Expected Output

Every push or pull request triggers an automated checkout, install, and test run.

Containerizing a Small Web Service

DOCKERFILE example with explanation and expected behavior.

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]

Why This Works

  • Choose a lightweight base image that already includes the runtime you need.
  • Set a working directory so later instructions remain consistent.
  • Copy dependency manifests first to improve rebuild performance through caching.
  • Expose the service port and define the startup command for deployment.

Builds an image that installs dependencies and starts the app on port 3000.
