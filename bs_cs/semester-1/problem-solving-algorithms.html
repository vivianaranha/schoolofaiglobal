Tracing Binary Search with Pseudocode

TEXT example with explanation and expected behavior.

BINARY-SEARCH(list, target)
    low <- 0
    high <- length(list) - 1

    WHILE low <= high
        mid <- floor((low + high) / 2)
        IF list[mid] = target
            RETURN mid
        ELSE IF list[mid] < target
            low <- mid + 1
        ELSE
            high <- mid - 1
    RETURN not found

Why This Works

  • Keep a search window defined by low and high indices.
  • Inspect the middle position instead of scanning every element.
  • Discard the half that cannot contain the target after each comparison.
  • Stop when the target is found or when the search window becomes empty.

Expected Output

For list [3, 7, 9, 14, 20] and target 14, the algorithm returns index 3.

Breaking a Problem into Reusable Functions

PYTHON example with explanation and expected behavior.

def average(scores):
    return sum(scores) / len(scores)


def grade(score):
    if score >= 90:
        return "A"
    if score >= 80:
        return "B"
    if score >= 70:
        return "C"
    return "Needs Improvement"

student_scores = [88, 92, 79, 95]
class_average = average(student_scores)
print("Class average:", round(class_average, 2))
print("Overall grade:", grade(class_average))

Why This Works

  • Separate calculation logic from grading logic so each part has one clear responsibility.
  • Reuse built-in aggregation functions to keep the code short and readable.
  • Return values from functions so other parts of the program can build on them.
  • Round the result at the presentation layer rather than inside the calculation function.

Expected Output

Class average: 88.5\nOverall grade: B
