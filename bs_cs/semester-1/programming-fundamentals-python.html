Classifying Numbers with Variables, Input, and Conditionals

PYTHON example with explanation and expected behavior.

number = int(input("Enter a number: "))

if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")

if number > 0:
    print("The number is positive")
elif number < 0:
    print("The number is negative")
else:
    print("The number is zero")

Why This Works

  • Convert the text typed by the learner into an integer so arithmetic works correctly.
  • Use the modulus operator to test even versus odd behavior.
  • Chain a second decision block to classify the sign of the number.
  • Print readable feedback that confirms both checks.

Expected Output

Breaking a Problem into Reusable Functions

PYTHON example with explanation and expected behavior.

def average(scores):
    return sum(scores) / len(scores)


def grade(score):
    if score >= 90:
        return "A"
    if score >= 80:
        return "B"
    if score >= 70:
        return "C"
    return "Needs Improvement"

student_scores = [88, 92, 79, 95]
class_average = average(student_scores)
print("Class average:", round(class_average, 2))
print("Overall grade:", grade(class_average))

Why This Works

  • Separate calculation logic from grading logic so each part has one clear responsibility.
  • Reuse built-in aggregation functions to keep the code short and readable.
  • Return values from functions so other parts of the program can build on them.
  • Round the result at the presentation layer rather than inside the calculation function.

Expected Output

Class average: 88.5\nOverall grade: B

Reading a File and Counting Important Patterns

PYTHON example with explanation and expected behavior.

from collections import Counter

with open("notes.txt", "r", encoding="utf-8") as file:
    words = file.read().lower().split()

counts = Counter(words)
for word, total in counts.most_common(5):
    print(word, total)

Why This Works

  • Open the file safely with a context manager so it closes automatically.
  • Normalize text by lowercasing before counting.
  • Use a built-in utility class instead of manually tracking counts in multiple branches.
  • Report only the most common values to keep the output useful.

Expected Output

data 7\npython 5\nlogic 4\nprogram 3\nfile 2
